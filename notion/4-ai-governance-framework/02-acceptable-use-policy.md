**Owner:** Compliance Officer (DPO) | **Applies to:** all staff, Committee members acting for the Club, and contractors

## Allowed

- Using approved tools (listed in the AI system inventory) for their approved purpose.
- Using public generative AI tools to draft general text (for example an event description) that contains no personal or confidential information.

## Not allowed

- Putting member, staff, caddie or visitor personal data, account details, CCTV images or confidential Club information into any AI tool that is not approved.
- Using AI to make or recommend decisions about people (membership, discipline, hiring) without the AI review group's approval.
- Presenting AI output to members as checked fact without checking it.
- Using AI to monitor staff.

## Always

- Check AI output before using it; you are responsible for what you send.
- Tell members when they are dealing with an AI system.
- Report anything that goes wrong (wrong output, data put in by mistake) to the Compliance Officer the same day.

## New tools

Ask the AI review group before using any new AI tool or AI feature in existing software.
