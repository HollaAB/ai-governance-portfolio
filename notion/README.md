# Notion Paste Pack

Ready-to-paste text for the portfolio's Notion site. Every file here is copied into Notion as it is; nothing needs to be written.

- `00-project-page.md` in each project folder is the full body of the project page: the template's 15 sections, filled in.
- The other numbered files are the project's subpages, in the order you create them.
- `0-case-study-organisation.md` is the Case Study Organisation page.

The subpage files are copies of the project documents with two changes: the first heading is removed (the Notion page title replaces it), and every link points to the full GitHub address, because short links stop working once pasted into Notion. They are generated by `build.py`; never edit them by hand.

```
            └── subpages, inside section 6         01-project-charter.md, 02-..., ...
                ├── Project Charter

```

Each project is one row in the Projects database. Clicking the row's name opens it as a page; that page is the project page. Its subpages are created **inside that page, in section 6 "Deliverables"**, so they sit under the project and appear as links in the Deliverables section.

## How to paste

1. Open the `.md` file in VS Code.
2. Select all (Ctrl + A) and copy (Ctrl + C).
3. Click on the empty line in Notion where the text should go and paste (Ctrl + V). Notion turns the headings, lists, tables, links and code blocks into Notion blocks.

### Lines to replace after pasting

The files contain three kinds of lines in square brackets. Each marks a place where Notion needs you to insert something that cannot be pasted.

| Line in the file | What to do |
|---|---|
| `[Replace this line: type /link to page and choose Case Study Organisation]` | Click at the end of the line, delete its text with Backspace until the line is empty, type `/link to page`, press Enter, choose `Case Study Organisation`. |
| `[Replace this line: /page Project Charter]` | Delete the line's text so the line is empty, type `/page`, press Enter. A new empty page opens. Type the title (`Project Charter`), then follow [Fill a subpage](#fill-a-subpage). |
| `[/embed: https://docs.google.com/... (Compliance Register)]` | The line already holds the sheet's share link. Select the link (from `https` to `usp=sharing`), copy it, delete the whole line's text, type `/embed`, press Enter, paste the link, click "Embed link". |
| `[/embed: paste the Risk and Control Register sheet link]` | The sheet does not exist yet. Build it, then do the same as above with its share link (or send Claude the link to add it to the files). |

Before leaving a page, press Ctrl + F and search for `[`: nothing in square brackets should remain.

## Build a project page

Do this once per project. Compliance Management System is the example; the other projects follow the same steps with their own folder.

1. **Create the row.** In the Projects database, click "New" and fill the title and properties as listed in the content plan.
2. **Open it as a page.** Click the row's title (or hover it and click "Open").
3. **Remove the template body.** The page opens with the grey fictional label at the top, then the template text from `Project status:` down to `Project Status Note`. Keep the label. Click in the `Project status:` line, press Esc (the block turns blue), then hold Shift and click the very last block of the page. Everything from `Project status:` to the end is now selected. Press Delete.
4. **Paste the page.** Click on the empty line under the fictional label and paste `00-project-page.md`.
5. **Section 4.** Replace the `/link to page` line with a link to Case Study Organisation.
6. **Section 6.** Replace each `/page` line with its subpage, in order, using the table for the project below.
7. **Check.** Ctrl + F for `[`; nothing should remain.

### Fill a subpage

1. On the new page, set the icon: hover above the title, "Add icon" > Icons tab > search `document` > colour Blue.
2. Click on the empty body and paste the file listed for that subpage.
3. If the page has a diagram (marked "Mermaid" in the tables below), click the pasted code block, make sure its language reads `Mermaid`, and switch the block to "Preview".
4. Replace any `[/embed: ...]` line with the sheet embed.
5. Go back to the project page with the link at the top left (the breadcrumb) and create the next subpage.

## Keeping the pack up to date

When a project document changes, regenerate the subpage files from the repository root:

    python3 notion/build.py

Then paste the changed file again into its Notion subpage (select all the old text on the subpage, delete it, paste). The `00-project-page.md` files are written by hand; edit them directly when a project's results change.
