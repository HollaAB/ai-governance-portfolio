# Incident Playbooks

> **Portfolio project.** This is an independent learning project using a fictional organisation and illustrative data. It is not an audit, legal opinion, or certification.

Draft 0.1, prepared for review by Abel Holla.

## Playbook 1: Staff account compromised (phishing)

| Step | Action | Who |
|---|---|---|
| 1 | Reset the password and end all sessions; confirm MFA is on | ICT Officer |
| 2 | Check the account's activity for the last 30 days: logins, exports, rule changes, sent mail | ICT Officer |
| 3 | If member or staff data was viewed or exported, start the breach response plan | DPO |
| 4 | Block the phishing sender and remove the email from all mailboxes | ICT Officer |
| 5 | If members may be targeted (for example fake payment requests), warn them within 24 hours with the correct paybill details | Membership and Events Manager |
| 6 | Record everything in the chronology | Incident lead |

## Playbook 2: Supplier data breach

| Step | Action | Who |
|---|---|---|
| 1 | Get written facts from the supplier: what data, how many people, when, contained or not | DPO |
| 2 | Escalate through the supplier's out-of-hours line if it is a weekend or night | ICT Officer |
| 3 | Start the 72-hour clock from when the Club became aware | DPO |
| 4 | Decide whether to suspend data flows to the supplier | General Manager |
| 5 | Assess and notify under the breach response plan; the Club, as controller, notifies the ODPC | DPO |
| 6 | Review the supplier's agreement and due diligence afterwards | Compliance Officer |

## Playbook 3: Physical security incident (intrusion or theft)

| Step | Action | Who |
|---|---|---|
| 1 | Make people safe; call the police if needed | Head of Security |
| 2 | Secure the scene; do not move items | Guard supervisor |
| 3 | Preserve CCTV footage at once (it overwrites after 30 days) using the chain-of-custody form | Head of Security |
| 4 | List what is missing or damaged; tell insurers | Finance Manager |
| 5 | If personal data was taken (for example files or a laptop), start the breach response plan | DPO |
| 6 | Report to the Security and Safety sub-committee | Head of Security |
