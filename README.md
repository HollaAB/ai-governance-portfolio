## Case study organisation

All projects are set in Kijani Heights Golf and Country Club, a fictional members' golf club in Kenya, so the evidence connects across compliance, governance and security. See the [organisation profile](scenario/organisation-profile.md).

## How to navigate

Each project folder has a README with the problem, approach, deliverables, testing, recommendations and limitations, plus a standard set of documents: project charter, version history, assumptions register, methodology, evidence index and limitations statement. CSV files open as tables on GitHub. Diagrams are written in Mermaid and render directly on GitHub.
