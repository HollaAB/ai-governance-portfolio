# Limitations: Security Risk and Incident Management

> **Portfolio project.** This is an independent learning project using a fictional organisation and illustrative data. It is not an audit, legal opinion, or certification.

- **Fictional organisation.** The Club, its accounts, staff, suppliers and incidents are invented.
- **No technical testing.** No real system was scanned or tested. The access review uses fictional account records; the phishing simulation and exercise are described scenarios.
- **No real security details.** Descriptions of systems and sites are general. Real configurations, network diagrams and vulnerabilities are never published.
- **Scenario results.** Scores, timings and test results are scenario results.
- **Framework use.** ISO 31000, NIST CSF 2.0 and ISO 22301 are used as structure only; no certification is implied.
